# AcademyCraft + ExtraAcademy 0.0.33

Minecraft 1.21.1 / NeoForge 21.1 / Java 21。私密仓库归档版。

- 技能接入明确的伤害类型和原生标签；修复手持突破附魔影响技能伤害及无关武器死亡消息。
- 空气分离的敌对伤害保留施法者，遵守原生 PVP、队伍友伤规则并保留击杀归属。
- 8 个 HUD 接入独立具名图层，支持逐层排序和取消；补齐通知、媒体及矢量波纹的 F1 隐藏；空间足够时，通知整组避让 CP 条和数值。
- 保留技能数值、既有注册 ID、能力存档 v4 和网络协议 v20。

验证：342 项 JUnit／契约检查、487 项 GameTest 已通过。19 项客户端检查通过，正常保存退出；18 张截图逐张核对。
构建与实测使用 NeoForge 21.1.248；其他21.1小版本和所有第三方整合包组合未逐一验证。测试中的重锤状态和原生投射物 tick 由探针驱动。

服务端测试通过后的变更仅限客户端 HUD 和客户端探针；JAR 条目比对确认服务端公共代码保持一致。

前期失败记录与夹具修正保存在 evidence/combat-hud-0.0.33。最终来源与二进制身份以 final-validation.json 和 SHA256SUMS.txt 为准。

已知布局边界：创造模式切换物品后的名称可能短暂与蓄力提示叠字；极窄窗口没有足够空间时通知保留原位置。

附件：发行主 JAR、对应源码 ZIP、SHA256SUMS.txt。客户端与服务端安装同一发行版本；audit-tests 探针不用于普通游戏。本次为私密 GitHub 发布。
