# 0.0.34-scex-modern 正式版

发布日期：2026-11-14。SCEX 非官方维护版本，适用于 Minecraft 1.21.1、NeoForge 21.1、Java 21。

## 主要内容

- 现代／经典双平衡模式，默认现代档。
- 完善技能、生物施法、技能同步与生命周期处理。
- 新增觉醒与重置按钮，改善界面交互。
- 支持奇点迭代供电、电池和配方联动，补充 KubeJS 接口。
- 生物技能不会默认全世界随机分配，整合包可按需配置。

## 安装与升级

客户端和服务端同时替换主 JAR，移除旧版 AcademyCraft，避免重复模组 ID。升级旧存档前备份世界和玩家数据。不要安装带 audit-tests 后缀的测试探针。JEI、Jade 等可选联动不是硬前置。
