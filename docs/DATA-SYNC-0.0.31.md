# AcademyCraft + ExtraAcademy 0.0.31 物品数据与同步

基线：`v0.0.30-scex-native-compat` / `887a8d4d2a5b8e836caac831d18c438c3300fe37`。
版本：`0.0.31-scex-data-sync`，Minecraft 1.21.1 / NeoForge 21.1 / Java 21。

## 本轮行为

- 电量使用 `academy:energy`，传送绑定使用 `academy:teleport_target` 原生数据组件，随原版物品保存、复制和菜单同步。读取优先级为新组件、旧 `academy_extra_energy`、旧 `DAMAGE`、空电量；旧默认空电量省略字段的存档也保持为空。只移除已迁移的本模组字段，保留其他 `CUSTOM_DATA`。电量不再占用耐久组件，容量、充能条和 `4 FE = 1 IF` 保持不变（注：能源单元 20 IF/次、便携开发机 50 IF/次的旧版单次传输带宽在本版并未实现，已于 audit batch3 补回）。
- 激光枪挖掘进度只存在于服务端动作状态，绑定玩家 UUID、物品实例、槽位、维度、目标方块状态和连续 tick。复制、保存、转交物品、切换槽位或维度不会继承进度；死亡、登出和停服清理临时状态。
- 玩家登录、重连、换维度和重生保留全量同步。技能、预设、教程等配置与 CP、过载、熟练度、冷却等运行态拆开；运行态每 5 tick 检查变化，配置每 20 tick 检查变化，显式操作仍可立即同步。发送差量字段，未变化时不重复发送。恢复延迟也同步到客户端以配合原有预测。
- 机器库存走原版菜单槽位包与 `ContainerData`，库存变化不再向跟踪区块的玩家广播完整物品 NBT。客户端菜单持有独立槽位缓存，外观更新不会清空菜单。矩阵只额外同步核心等级和材料齐备状态；机器磁盘库存格式保持不变。

已有注册 ID、技能数值、能力存档 v4 保持不变。网络协议升为 `academy-1.21.1-payload-v20-data-v4`，客户端和服务端必须配套升级。旧物品首次读取会迁移；回退到旧版本需要恢复升级前备份，不能只替换旧 JAR。

本批不包含下一阶段的漏斗、流体容器、配方缓存或原生界面控件改造。

## 验证边界

本轮复用原 443 项 GameTest 范围并增加物品迁移、玩家同步和机器同步场景，保留原有 342 项 JUnit 检查。最终实际执行数、通过状态、JAR / 源码身份及日志以 `evidence/data-sync-0.0.31/final-validation.json` 为准；计数不表示完整第三方整包覆盖率。

新增实际测试使用原生 ItemStack 保存读取和网络 codec、真实连接的玩家、原版复活请求处理器、自然 tick 恢复与冷却、双查看者原版菜单包。真实客户端检查直接读取已收到的数据，不直接写入客户端能力或库存。Vicerach 使用原冻结底座，服务端与客户端串行运行、独占测试锁、1536 MiB 堆和 2 个 CPU 工作线程。

网络指标记录实际发送／接收的包数，并以生产 codec 计算编码字节。对照是相同资料按 0.0.30 全量格式重建的字节数，排除 TCP 帧和压缩开销，不作为整服线速或 MSPT 收益。最终实测值见同一验证回执。

诊断过程保留：复活夹具最初绕过原版请求处理器，后改用 `PERFORM_RESPAWN` 并检查新玩家与监听器绑定；弹幕夹具移入自身测试结构并清理自身对象，保留原有精确命中和实际伤害断言。玻璃碰撞夹具封闭平台侧面和后端，排除从低处合法绕行的路径，三种追击场景独立分批；影子生成点移入结构内，避免随机结构起点恰在区块边界时落入未运行的相邻区块。原碰撞边界、伤害和扣费断言不变。

客户端快速跨维后立即停止曾卡在原生 `ChunkMap.scheduleUnload` 重排队列。探针收尾改为在正常服务端 tick 中等待区块生成和保存状态连续 20 tick 就绪，再执行原生保存检查点并退出；验收还要求全部维度保存及进程正常退出。生产技能、区块管理和机器规则未因测试夹具调整而改变。

既有 `ownerAttackNavigatesAroundObstacleAndPays` 在 `gt-r3` 出现一次绕障后未命中目标；本轮其他三次完整运行及最终 `gt-r4` 均通过原断言。仅补充自然路径观测，未调整生产 AI、伤害断言或时限。该次偶发失败的具体成因尚未确定，原始失败日志及独立复核保留，不将最终通过表述为已消除导航测试的全部偶发性。

## 构建与发行

```powershell
.\scripts\generate-build-info.ps1
.\gradlew.bat --offline --no-daemon --no-configuration-cache --console=plain --max-workers=2 check build auditTestJar
```

构建锁定 NeoForge 21.1.248，运行范围保持 `[21.1,21.2)`。`--offline` 要求依赖已缓存。主 JAR 与独立 `audit-tests` 探针分包；私密 GitHub Release 仅提供主 JAR、对应源码 ZIP 和 `SHA256SUMS.txt`。本批不部署生产服务端或玩家更新器。
